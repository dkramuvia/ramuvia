# 요금제 숫자가 서로 다릅니다 — 확인 요청

작성: 2026-09-28 · 개발팀

2026-09-28 피그마에 **실제 가격과 등급별 제한**이 들어왔습니다.
그런데 지금 서버에 들어 있는 값과 여러 군데가 다릅니다. **서버 값이 실제로 동작하는
값**이라, 화면에 적힌 것과 다르면 "20개까지 된다고 써 있는데 4개에서 막힌다" 가 됩니다.

---

## 1. 가장 큰 문제 — 데이터 보관 기간

피그마 요금제에 **"데이터 서버 저장 기간"** 이 새로 생겼습니다.

| 등급 | 피그마 |
|---|---|
| 베이직 | **7일** |
| 플래티넘 | **15일** |

그런데 9월 17일·22일에 드린 문서에는 **"서버 위치·이동 경로는 6개월 후 파기"**(WBS 기준)
로 되어 있고, 그 기준으로 저장 구조와 비용을 계산했습니다.

**7일과 6개월은 26배 차이입니다.** 어느 쪽이 맞는지에 따라 달라지는 것:

- 서버 비용 (100만 대 기준 월 7,845달러 ↔ 그보다 훨씬 적음)
- 아직 답을 못 받은 **"요약 보관" 결정 자체가 필요 없어질 수도** 있습니다
  (7일이면 전부 원본으로 둬도 양이 얼마 안 됩니다)
- 이상징후 판정 (48시간 기준은 7일 안에 들어가므로 문제없음)
- "석 달 전 어디 있었나" 는 **불가능해집니다**

> 등급마다 보관 기간이 다르면, 무료 사용자의 위치는 7일 뒤 사라집니다.
> 노인(케어) 등급이 무료인데, **가장 오래 보관해야 할 대상이 가장 짧게 보관**되는 셈입니다.
> 이 부분은 특히 확인이 필요합니다.

## 2. 숫자가 다른 항목

| 항목 | 피그마 (09-28) | 서버 (현재) |
|---|---|---|
| 베이직 · 장소 등록 | **5개** | 4개 |
| 베이직 · 안심존 알림 | **2개** | 0개 (불가) |
| 베이직 · 관공서 연락 | **1건** | 제한 없음 (항목 자체가 없음) |
| 플래티넘 · 안심존 알림 | **5개** | 10개 |
| 플래티넘 · SOS 전송 | **3명** | 10명 |
| 플래티넘 · 관공서 연락 | **3건** | 항목 없음 |

**베이직의 안심존 알림**이 특히 중요합니다. 지금 서버는 0개(무료는 못 씀)인데
피그마는 2개입니다. 어제 만든 안심장소 기능이 무료 사용자에게 보일지 말지가 갈립니다.

## 3. GPS 전송 속도 표기

피그마는 `LOW / MID / HIGH` 로 적혀 있는데, 서버는 초 단위 숫자입니다
(`gpsIntervalMovingSec`: 베이직 20초, 유료 10초).

화면에 초를 그대로 보여 줄지, LOW/MID/HIGH 로 뭉뚱그릴지 정해야 합니다.
**관리자 페이지에서 초를 바꿀 수 있으므로**, 화면에 초를 박아 두면 값을 바꿀 때마다
문구가 틀어집니다. LOW/MID/HIGH 표기가 그 점에서는 낫습니다.

## 5. 개발팀 제안

**서버 값을 피그마에 맞추는 것이 맞다고 봅니다.** 화면은 사용자에게 약속한 것이고,
서버 값은 관리자 페이지에서 언제든 바꿀 수 있습니다.

다만 **보관 기간(1번)만은 결정을 받아야** 합니다. 이건 관리자 페이지 값이 아니라
저장 구조와 비용이 달린 문제이고, 한번 지운 것은 되살릴 수 없습니다.

나머지(2~4번)는 확인만 주시면 그날 반영합니다.
