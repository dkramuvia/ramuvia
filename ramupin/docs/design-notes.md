# 디자인 확인 사항 (퍼블리싱 중 발견)

피그마 [라무핀 v2.0 > 설명] 페이지를 코드로 옮기면서 발견한, 디자이너 확인이 필요한 부분입니다.
코드는 아래 **"현재 적용"** 기준으로 만들었고, 확정되면 `src/theme` 과 `src/components/ui` 만 고치면 됩니다.

| # | 내용 | 현재 적용 |
|---|---|---|
| 1 | 피그마에 공식 컬러·텍스트 스타일이 없음 (로컬 스타일은 그림자 4개, `premium` 1개뿐) | 화면에서 많이 쓰인 값으로 토큰을 만듦 (`src/theme/colors.ts`, `typography.ts`) |
| 2 | 글꼴이 섞여 있음: SUIT 외에 Geist, Space Grotesk, Pretendard, Inter, Helvetica 등 (UI 키트 컴포넌트에서 들어온 것으로 보임) | 전부 SUIT |
| 3 | 주요 버튼 색이 화면마다 다름: 파랑 `#0095FF`, 갈색 `#473C39` / `#5B4F4B` / `#7C6D67` | 파랑 = 주요 CTA, 갈색 3종은 피그마 화면 그대로 |
| 4 | 스위치가 2종: 친구별 상세 공유(초록/회색 + 흰 원), 알림 설정(파랑/회색 + 검은 원) | 초록 스타일 하나로 통일 |
| 5 | 하단 탭 글자: 피그마 텍스트는 `gallery` / `people` 소문자, 렌더링 결과는 `Gallery` / `People` | `Gallery` / `Map` / `People` |
| 6 | 사람들 > 메시지 탭의 채팅방 목록 디자인 없음 | 친구 리스트 카드 형태로 임시 구성 |
| 7 | 토스트(저장 완료 등) 디자인 없음 | Android 기본 토스트 |
| 8 | 알림 보관함(WBS 9.7), 네이버·카카오 로그인 버튼 디자인 없음 | 미구현 |
| 9 | 지도 메인의 "친구 요청 N 배지" 위치·색이 화면에 없음 (기획 메모에만 있음) | "친구 (6)" 옆 빨간 원 N |
| 10 | 3D 탭 아이콘은 1024px 원본을 156px로 줄여 사용. 비선택 상태는 피그마와 같이 채도 제거 + 투명도 60% | - |
| 11 | 갤러리 업로드: 피그마는 앱 안에 기기 사진 목록(최근)을 보여줌 | OS 사진 선택기 사용. 앱 안 목록은 expo-media-library 추가 필요 (네이티브 재빌드) |
| 12 | 장소명 "삼성 코엑스" 같은 POI 이름 | 기기 Geocoder 로는 거의 안 나와 주소만 표시. 서버/Places API 필요 |
| 13 | 사용자 ID로 친구 추가 화면 없음 | 입력 팝업으로 구성 |
| 14 | 내 QR "저장" 버튼 | 공유 시트로 대체. 이미지 저장은 expo-media-library 필요 |
| 15 | 친구 등록 완료 문구 "이제 서로의 위치를 알 수 있어요" ↔ WBS 6.8(친구 추가 시 위치 미공유) 충돌 | 피그마 문구 유지, 기획 확정 필요 (wbs-check §2-4) |
| 16 | 1:1 채팅방에서도 연속 메시지마다 아바타·이름 반복 여부 | 같은 사람 연속 메시지는 첫 메시지에만 표시 |
| 17 | 하단 탭 선택 표시: 피그마는 탭 바 아래로 반쯤 걸친 원(19px). 안드로이드는 아래 시스템 버튼 줄 때문에 잘린 것처럼 보임 (09-15 확인) | 탭 이름 아래 온전한 점(6px) |
