# 지도를 셋 쓰는 이유와 고르는 규칙

작성: 2026-09-18 · WBS 4.4, 10.5

---

## 1. 규칙

| 지금 위치 | 등급 | 쓰는 지도 |
|---|---|---|
| **해외** | 해외 지도 가능 (`features.overseasMap`) | **Mapbox** |
| 해외 | 그 외 | 구글 |
| 국내 | 유료 + 설정에서 네이버 선택 | 네이버 |
| 국내 | 그 외 | 구글 |

코드는 [`src/features/map/region.ts`](../src/features/map/region.ts) 한 곳에 있습니다.

**해외에서는 네이버를 쓰지 않습니다.** 유료 등급이 네이버를 골라 뒀더라도, 나가면 지도가 비어 버리기 때문입니다.

### 왜 셋인가

| 지도 | 강점 | 약점 |
|---|---|---|
| **네이버** | 국내 장소명·도로명주소가 가장 정확, **로드뷰** | 해외가 거의 비어 있음 |
| **Mapbox** | 전 세계, 오프라인 지도 | 한국 데이터가 약함, **지도 로드 건당 과금** |
| **구글** | 어디서나 됨, 추가 비용 없음 | 국내 장소명이 네이버보다 부족 |

### 국내/해외는 어떻게 아나

좌표가 한국 영역 사각형(위도 32.9~38.7, 경도 124.5~132.0) 안인지로만 봅니다.
울릉도·독도·마라도까지 들어갑니다.

서버에 물어보지 않는 이유: 지도를 띄울 때마다 요청이 생깁니다. 이 판정은 "어느 지도를 띄울까"에만 쓰이고,
틀려도 다른 지도가 나올 뿐이라 사각형으로 충분합니다.

> **알려진 한계** — 쓰시마(일본)가 이 사각형 안에 들어갑니다. 배로 그 근처에 가면 네이버 지도가 뜨는데
> 그 지역은 비어 있습니다. 실제로 겪을 일이 드물어 그대로 뒀습니다.

## 2. Mapbox 붙이기

09-18 적용 완료. `@rnmapbox/maps@10.3.5` (RN 0.86 지원).

### 토큰 두 개

| 토큰 | 종류 | 어디에 | 저장소에 올라가나 |
|---|---|---|---|
| SDK 내려받기 | **`sk.*` (비밀, `DOWNLOADS:READ`)** | `~/.gradle/gradle.properties` 의 `MAPBOX_DOWNLOADS_TOKEN` | **아니오** |
| 지도 불러오기 | `pk.*` (공개) | `.env` 의 `EXPO_PUBLIC_MAPBOX_ACCESS_TOKEN` | 아니오 (.env 는 제외) |

> `sk.` 토큰을 `app.config.ts` 에 적으면 저장소에 올라갑니다. 절대 넣지 마세요.
> 메신저·메일에 한 번이라도 올라갔으면 폐기하고 새로 발급해야 합니다.
>
> 참고: prebuild 가 만드는 gradle 에 "Authentication is no longer required as per Mapbox's
> removal of download token requirement" 주석이 붙습니다. `sk.` 토큰이 이제 없어도 될 수 있지만,
> 있어도 문제되지 않아 그대로 둡니다.

### 다른 지도와 다른 점

| | 구글·네이버 | Mapbox |
|---|---|---|
| 확대 정도 | 위도 범위(delta) | 줌 단계 — `zoomFromDelta()` 로 변환 |
| 마커 | 여러 자식 가능 | 자식 하나만 → `View` 로 감쌈 |
| 원·선 | 컴포넌트 하나씩 | **GeoJSON 한 덩어리 + 레이어 하나** (개수가 늘어도 레이어는 그대로) |
| 원 반경 | **미터** | **화면 픽셀** ← 아래 참고 |

> **GPS 감도 원이 정확하지 않습니다.** 구글·네이버는 "반경 50m" 처럼 미터로 그릴 수 있는데
> Mapbox `CircleLayer` 는 화면 픽셀 단위입니다. 줌에 따라 커지도록 맞춰 뒀지만 정확한 미터 원은 아닙니다.
> 해외에서 감도 원이 중요해지면 폴리곤으로 바꿔야 합니다.

### 09-21 실기기 확인 결과

임시로 "해외" 취급하도록 바꿔 갤럭시에서 확인했습니다.

| 항목 | 결과 |
|---|---|
| SDK 로드 · 토큰 | ✅ 지도가 정상적으로 그려짐 |
| 한글 상호명 | ✅ 나옴 ("델리커리 가산현대아울렛점" 등). 도로명은 로마자 |
| 내 마커 | ✅ |
| 국내 지도 회귀 | ✅ 구글·네이버 이상 없음 |

**남은 것 (해외 실사용 전 확인)**

- **확대 정도가 구글보다 촘촘합니다.** `zoomFromDelta()` 가 화면 크기를 고려하지 않아 그렇습니다.
  실제 해외 좌표로 한 번 맞춰야 합니다
- **친구들에게 맞춰 확대되는 동작(fitTo)** 이 화면에서 확인되지 않았습니다.
  지도 준비 전 요청을 보류하는 처리는 넣었으나, 해외 좌표로 다시 봐야 합니다
- 경고 한 줄: `Can't perform a React state update on a component that hasn't mounted yet`
  (동작에는 영향 없음, rnmapbox 내부로 추정)

### 비용

Mapbox 는 **지도를 띄울 때마다** 과금됩니다 (월 5만 로드까지 무료).
해외에 있는 유료 사용자만 쓰므로 당장은 크지 않지만, **해외 사용자가 늘면 확인이 필요합니다.**
등급 설정에서 언제든 끌 수 있습니다 (관리자 화면 > 기능 > 해외 지도).

## 3. 관리자 화면에서 바꾸기

`관리자 화면 > 등급별 설정 > 기능`

| 항목 | 뜻 |
|---|---|
| 프리미엄 지도 | 국내에서 네이버 지도·로드뷰 |
| **해외 지도 (Mapbox)** | 해외에서 Mapbox. 꺼 두면 해외에서 구글 |

사용자 한 명만 켜 주는 것도 됩니다 (사용자별 예외).
