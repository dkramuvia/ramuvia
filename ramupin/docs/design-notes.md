## 다크 모드 전환 방법 (2026-09-28~)

피그마에 다크 모드 130개 화면이 생겼습니다. 색을 쓰는 방식 자체를 바꿔야 합니다.

### 왜 한꺼번에 못 바꾸나

`colors` 를 쓰는 파일이 **98개**이고, 대부분 파일 맨 아래 `StyleSheet.create` 안에 있습니다.
그건 앱이 뜰 때 **한 번만** 계산돼서, 나중에 테마가 바뀌어도 그 색 그대로 남습니다.

### 바꾸는 방법

**색이 들어가는 스타일**은 `makeStyles` 로 감쌉니다.

```tsx
// 전
import { colors } from '@/theme';
const styles = StyleSheet.create({ box: { backgroundColor: colors.surface } });

// 후
import { makeStyles } from '@/theme';
const useStyles = makeStyles((colors) => ({ box: { backgroundColor: colors.surface } }));

function Screen() {
  const styles = useStyles();   // ← 이 줄 추가
```

**렌더에서 직접 쓰는 색**(`color={colors.text}`)은 `useColors()` 로 바꿉니다.

```tsx
const colors = useColors();
```

색이 안 들어가는 스타일(여백·크기)은 그대로 둬도 됩니다.

### 어디까지 했나

- [x] 팔레트 두 벌 (`src/theme/palettes.ts`)
- [x] 테마 고르기 (`useColors`, `makeStyles`, `useThemeName`) — 기본은 **기기 설정을 따라감**
- [x] 설정값 `appTheme` (auto / light / dark)
- [x] 공용 컴포넌트 전부
- [x] 화면 전부 (`colors` 를 직접 쓰는 파일이 남지 않았습니다)
- [x] **다크 팔레트 실제 값** — 피그마 다크 페이지를 그림으로 받아 픽셀에서 뽑았습니다
      (`scripts/sample-colors.mjs`). 파일 조회가 속도 제한에 걸려 있어 쓴 방법입니다
- [x] 다크에서 눈으로 확인 (폰 R3CN809EP2Y, 2026-09-29) — 아래 "폰에서 찾은 것" 참고
- [ ] 글자·선 색 재확인 — 그림에서 가는 것은 흐려져 정확하지 않을 수 있습니다.
      피그마 조회가 풀리면 그 값으로 한 번 맞춰 보는 것이 좋습니다

### 피그마가 속도 제한(429)에 걸렸을 때

파일 조회(`/v1/files/...`)는 막혀도 **이미지(`/v1/images/...`)는 열려 있습니다.**
화면을 그림으로 받아 `scripts/sample-colors.mjs` 로 색을 셀 수 있습니다.
유료 결제와는 무관하고, 시간이 지나면 저절로 풀립니다.

### 폰에서 찾은 것 (2026-09-29)

타입 검사로는 하나도 안 잡히는 종류입니다. **색은 맞는데 조합이 틀린** 것이라,
화면을 열어 봐야만 드러납니다. 크게 네 갈래였습니다.

**1. 지도 위 요소가 앱 화면 색을 따라감**

설정에는 서로 다른 두 가지가 있습니다 — 앱 화면 색(`appTheme`)과 지도 스타일(`mapTheme`).
앱만 다크로 두면 지도는 밝은데 그 위 글자가 흰색이 됩니다.
지역명·날씨·SOS·내 위치·로드뷰 버튼이 통째로 안 보였습니다.

→ `src/theme/mapOverlay.ts` 한 곳에서 정합니다. 지도 위에 얹는 것은
`useMapOverlay()` / `makeMapStyles()` 를 쓰세요. 지도 스타일이 다크이거나
위성 사진이면 어두운 쪽으로 갑니다.

**2. `colors.white` 를 카드 바탕으로 씀**

`white` 는 "흰색"이라 다크에서도 흰색입니다. 그 위 글자만 밝아져서
**흰 바탕에 흰 글자**가 됐습니다. 입력칸이 특히 심해서 글자를 쳐도 안 보였습니다.

→ 뜻으로 이름을 나눴습니다.
`white`(지도·사진 위의 진짜 흰색) / `card`(카드 바탕) / `inputBackground` /
`chatBackground` / `chatBubbleMine`. 새로 만들 때도 이 기준으로 고르세요.

**3. 배경은 고정인데 글자만 테마를 따라감**

구독 플랜(#232323)과 무료 체험(파스텔 그라데이션)은 라이트에서도 어둡거나 밝습니다.
배경이 고정이면 그 위 글자도 고정이어야 합니다.
히스토리의 SOS 칸(연분홍), 요금제 "연간 -20% off" 칩이 같은 경우였습니다.

**4. 맨 위 시계·배터리**

앱 전체에 "검정"으로 박혀 있어 다크에서 검은 배경에 검은 글자였습니다.
→ `ThemedStatusBar`. 사진·그라데이션 위 화면은 `style="light"`/`"dark"` 를 직접
쓰고, 지도 화면은 지도 밝기를 따릅니다.

### 네이티브 재빌드가 필요한 것

- **`userInterfaceStyle`** — `app.json` 에 `"light"` 로 박혀 있어서, 앱이 기기 설정을
  물어보면 **늘 "라이트"라는 답**을 받았습니다. 그래서 앱 화면 색을 "기기 설정"으로
  두고 폰을 다크로 바꿔도 앱은 밝은 채였습니다 (2026-09-29 폰에서 확인).
  `"automatic"` 으로 고쳤지만, 이 값은 안드로이드 빌드에 구워지는 것이라
  **다음 네이티브 빌드부터 적용됩니다.** 그전까지는 설정에서 직접 "다크"를 고르면 됩니다
- **아래 시스템 버튼 줄**이 다크에서도 흰색으로 남습니다 (`expo-navigation-bar` 필요)

### 아직 눈으로 못 본 것

- **친구별 맞춤 알림** — 친구가 0명이라 화면까지 못 갔습니다.
  소스에는 박아 둔 색이 없어 문제가 없을 것으로 보입니다
- **가입·온보딩 화면** — 로그인을 풀어야 볼 수 있습니다

### 디자이너에게 물어볼 것

- **`CountActionBar` 의 "친구 추가하기" 버튼** (`#ACA09C` 바탕 + 흰 글자) —
  라이트·다크 둘 다 글자가 잘 안 읽힙니다. 피그마 값 그대로라 건드리지 않았습니다
- **채팅 말풍선** — 다크 화면의 말풍선 색을 받지 못해, 상대는 카드색,
  나는 그보다 한 단계 밝게 임의로 정했습니다

### 일부러 테마를 안 따르게 둔 것

- **경로선 색** (`routeLayers.ts`) — 노랑=머무름, 파랑=이동. 지도 위에서 뜻을 나타내는
  색이라 라이트·다크 어느 쪽에서도 같아야 합니다
- **브랜드 로고 색** (`welcome.tsx`) — 페이스북 파랑, 구글 빨강은 각 회사가 정한 색입니다.
  다만 X·Apple 은 **한 가지 색 마크**라 밝은 데선 검정, 어두운 데선 흰색으로 씁니다
  (두 회사 가이드도 그렇습니다)
- **배지 색** (`StatusBadge.tsx`) — 피그마가 라이트·다크 배지를 따로 그려 둔 것이라
  테마가 아니라 배지 종류(내 것/친구 것)로 갈립니다
- **지도 마커·스위치 손잡이의 흰색** — 지도 위라 늘 흰색이 맞습니다

### 남은 것을 할 때

`palettes.ts` 의 다크 값만 고치면 화면 코드는 건드릴 필요가 없습니다.
그게 이렇게 나눈 이유입니다.
