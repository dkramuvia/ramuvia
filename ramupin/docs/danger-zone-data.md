## 2. 후보 세 곳

### ① 전국재해위험지구표준데이터 (행정안전부)

<https://www.data.go.kr/data/15013202/standard.do>

- 무료, 이용허락 제한 없음, JSON, 일 1회 갱신
- 항목: 재해위험지구명 · 등급코드 · **유형코드** · 상세유형코드 · 시설명 · 지정사유 · 해제일자
- **문제: 위도·경도가 없습니다.** 행정구역과 시설명만 줍니다

> 좌표가 없으면 "여기 들어왔다" 를 판정할 수 없습니다.
> 우리 표는 좌표와 반경으로 원을 그려 판정하기 때문입니다.

**해결 방법**: 서버에 이미 **네이버 주소→좌표 변환**이 있습니다
(`NAVER_MAP_CLIENT_ID/SECRET`, 주소 검색용으로 붙여 둔 것). 지구명·시설명을 주소로 보고
좌표로 바꿔 넣으면 됩니다. 다만 **반경은 자료에 없어 우리가 정해야 합니다.**

### ② 재난안전데이터공유플랫폼 (행정안전부)

<https://www.safetydata.go.kr/>

- 위 ①을 포함해 재난안전 자료를 모아 REST API(JSON/XML)로 줍니다
- **회원 가입 + 활용 신청 + 인증키 발급**이 필요합니다 (공지사항 → 인증키발급, 즉시 발급)

### ③ 생활안전지도 개발자센터 (행정안전부)

<https://www.safemap.go.kr/dvct/crtfc/addCrtfcKey.do>

- 지도 위에 겹쳐 그리는 **레이어(WMS/WFS)** 형태로 보입니다
- 인증키 신청 시 **서비스할 웹사이트 도메인**을 적어야 합니다
- 레이어는 "지도에 그리기" 에는 좋지만, **"이 좌표가 위험지역 안인가" 판정에는 그대로 쓸 수 없습니다.**
  판정을 하려면 좌표 목록이 필요합니다

### 침수흔적도 (참고)

<https://www.data.go.kr/data/15101791/openapi.do> · 서울시 별도 자료도 있음

- WMS(지도 이미지) 위주라 ③과 같은 한계

## 3. 권하는 방법

**① 표준데이터 + 우리 서버의 주소→좌표 변환**

1. 대표님이 [공공데이터포털](https://www.data.go.kr/data/15013202/standard.do) 또는
   [재난안전데이터공유플랫폼](https://www.safetydata.go.kr/) 에서 **인증키를 신청**합니다
   (제가 대신 할 수 없습니다 — 기관 회원 가입과 활용 목적 기재가 필요합니다)
2. 받은 키를 서버 `.env` 에 넣습니다
3. 제가 받아오기 스크립트를 만듭니다: 자료 조회 → 주소를 좌표로 → `config.danger_zones` 에 넣기
4. 하루 한 번 갱신합니다 (자료가 일 1회 갱신이므로)

**반경은 우리가 정해야 합니다.** 자료에 없습니다. 유형별로 다르게 잡는 것이 좋습니다:

| 유형 | 반경(안) | 이유 |
|---|---|---|
| 낙석·급경사지 | 100~200m | 도로 한 구간 |
| 침수 | 300~500m | 구역 단위 |
| 기타 | 200m | |

> 너무 크게 잡으면 도심에서 계속 울리고, 너무 작으면 지나쳐도 안 울립니다.
> **대표님 확인이 필요합니다.**

---

## 4. 대표님이 해주실 것

- [ ] 공공데이터 인증키 신청 (위 ① 또는 ②)
- [ ] 유형별 반경 확정
- [ ] 어느 유형까지 알릴지 (낙석만? 침수까지? 전부?)

키만 주시면 받아오기까지 **반나절이면 됩니다.** 표와 판정·알림은 이미 돌아갑니다.

---

## 5. 직접 넣어 볼 때

자료를 기다리는 동안 손으로 넣어 시험할 수 있습니다.

```sql
INSERT INTO config.danger_zones (name, kind, latitude, longitude, radius_m, source)
VALUES ('북악산로 낙석 주의 구간', 'rockfall', 37.5960, 126.9780, 200, 'manual');
```

`source` 와 `source_key` 로 묶어 두었으므로, 나중에 공공데이터를 부어도
손으로 넣은 것과 섞이지 않습니다.
