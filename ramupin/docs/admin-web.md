# 관리자 화면

작성: 2026-09-18 · 고침: 2026-10-06 (관제센터 01) · WBS 11.4~12.1

앱에 숫자를 박지 않는다는 원칙(WBS 2.1)을 실제로 쓸 수 있게 만든 화면입니다.
**수집 주기를 바꾸려고 앱을 다시 배포할 필요가 없습니다.**

주소: `http://<서버>/admin`

## 0. 관제센터 틀 (2026-10-06, 피그마 `관리자` 파일)

왼쪽 메뉴 + 상단 바 + **라이트/다크 모드** 구성으로 바꿨습니다. 다크 모드는 왼쪽 위 버튼으로
바꾸고, 고른 값은 그 브라우저에 남습니다 (처음에는 운영체제 설정을 따릅니다).

피그마 화면 01~05 중 지금 만든 것은 **01 종합 모니터링** 하나입니다. 02~05가 생길 때까지
기존 기능은 메뉴에 그대로 둡니다.

| 메뉴 | 화면 | 상태 |
|---|---|---|
| 모니터링 › 종합 모니터링 | 피그마 01 | **완료** — 첫 화면 |
| 모니터링 › 이상징후 · SOS | 아래 1장 | 기존 기능 (피그마에 없음) |
| 운영관리 › 사용자별 예외 | 아래 2장 | 피그마 02·03 사용자별 설정으로 바뀔 자리 |
| 시스템 설정 › 등급별 설정 | 아래 2장 | 피그마 04 등급·요금 관리로 바뀔 자리 |
| 시스템 설정 › 변경 이력 | 아래 5장 | 기존 기능 |

상단 배지는 접속 주소를 보고 `DEV · localhost:3000` / `PROD · Global` 로 나옵니다.
운영 화면인 줄 모르고 값을 바꾸는 일을 막기 위해서입니다.

### 01 종합 모니터링

국가·등급 단위 **집계만** 보여 줍니다. 개인별 결제 내역은 없습니다. API는 `GET /admin/api/overview` 입니다.

| 칸 | 내용 |
|---|---|
| KPI 4개 | 전체 다운로드 · 전체 가입자 · 활성 사용자(MAU, 최근 30일) · 다운로드 대비 활성화율 |
| 막대 차트 | 국가마다 막대 2개 (연한색 / 진한색 = 활성 사용자). 상위 8개국 + '기타' |
| 국가별 표 | 다운로드 · 가입자 · 활성 사용자 · 활성화율 · 유료 · 무료 · 1인가구 · 노인 |
| 등급별 표 | 결제1~5 사용자 수와 비중. 결제99(관리자)는 빠집니다 |
| 도넛 | 무료(베이직) / 유료(플래티넘+트리니티) / 노인(케어) / 1인가구(가디언) |

- **유료·무료·1인가구·노인은 활성 사용자 안에서 셉니다.** 네 칸을 더하면 활성 사용자와 같고, 등급별 표·도넛과 숫자가 맞습니다.
- 1인가구(가디언)·노인(케어)은 국내 전용이라 한국 외 국가는 `-` 로 나옵니다.
- **다운로드 수는 출시 전이라 비어 있습니다.** Google Play Developer API와 App Store Connect API를 붙여야 하는 값입니다.
  그 동안 차트의 연한 막대는 **가입자**, 표의 활성화율은 **가입자 대비**로 바꿔 보여 주고, 제목에 그렇게 적어 둡니다.
- 월 요금은 지금 화면에 적어 둔 값입니다 (베이직·케어·가디언 0원, 플래티넘·트리니티 미확정). 04 등급·요금 관리가 생기면 거기서 받아 옵니다.
- 국가 이름은 브라우저가 ISO 코드(`KR`)를 한국어(`대한민국`)로 바꿔 보여 줍니다. 따로 번역표를 두지 않습니다.

## 1. 이상징후 · SOS

**여기 뜬 분께는 회사가 직접 전화합니다** (09-17 대표 확정).
확인콜·출동 기록 시스템은 만들지 않습니다.

1인단독 사용자는 친구에게 알림이 가지 않고 **이 목록에만** 나타납니다.

| 열 | 내용 |
|---|---|
| 발생 | 시각 + "3시간 전" |
| 대상 | 이름 / ID / **1인단독 표시** |
| 상황 | "위치 고정 24시간" — 24h는 주황, **48h는 빨강** |
| 구분 | 관제 / 친구 알림 |
| | 상세 · **확인함** |

"확인함"을 눌러도 목록에서 사라지지 않고 표시만 바뀝니다. 실제로 풀리는 것은
**본인이 다시 움직이거나 전화기를 켰을 때** 자동으로 됩니다 (09-17 확정).

### 상세 화면

전화를 걸지 판단하는 데 필요한 것만 있습니다.

- 마지막 위치 수신 시각 (네이버 지도 링크)
- 배터리 + 충전 여부
- **이 자리에 머물기 시작한 시각**
- 배터리 0% 시작 시각
- **지난 기록 30건** — 이번이 처음인지, 늘 그러시는지에 따라 대응이 달라집니다

판정 규칙은 [anomaly-alerts.md](./anomaly-alerts.md) 에 있습니다.

> 이 화면은 **관리자 로그인**으로만 열립니다. 남의 실시간 위치가 보이므로
> 앱 사용자 아무나 볼 수 있으면 안 됩니다.

## 2. 무엇을 바꿀 수 있나

| 묶음 | 항목 |
|---|---|
| **위치 수집** | 이동 중 확인 주기 · 머무는 중 확인 주기 · 서버 전송 주기 |
| 제한 | 안심 장소 수 · 단일 위치 수 · 진입·이탈 알림 대상 수 · 예약 메시지 수신인 수 · SOS 수신인 수 · 사진 용량 |
| 기능 | 광고 · 프리미엄 지도 · 교통·날씨 · 과속 경고 · 재난 문자 |

항목 정의는 `src/admin/policy-fields.ts` 한 곳에 있습니다. **여기에 항목을 추가하면 화면에도 자동으로 나타납니다.**

### 등급별 / 사람별

- **등급별 설정** — 베이직·플래티넘·트리니티·케어·가디언. 그 등급 사용자 전체에 적용됩니다.
- **사용자별 예외** — 한 사람만 다르게. 등급 설정보다 우선합니다. 예: 치매 어르신 한 분만 더 촘촘하게.
  비워 두면 등급 기본값을 따르고, "예외 삭제"로 되돌립니다.

### 바꾸기 전에 얼마나 늘어나는지 보여 줍니다

주기를 입력하면 그 자리에서 계산해 보여 줍니다.

> 이 설정이면 기기 1대가 하루에 **1,800건**을 모으고 **1,440번** 전송합니다. 10만 대 기준 하루 **1.80억 건**.

20초 이하로 내리면 한 번 더 확인을 묻습니다. 비용 계산 근거는 [server-cost-estimate.md](./server-cost-estimate.md).

## 3. 값이 앱까지 가는 길

```
관리자 화면  →  config.plan_policies (JSONB)
                  ↓  GET /me/policy  (등급 정책 + 사용자별 예외를 합쳐서)
              앱 react-query 캐시
                  ↓  savePolicySnapshot
              기기 저장소 (policy-snapshot)
                  ↓
              백그라운드 위치 수집
```

기기에 따로 저장하는 이유: 안드로이드가 앱을 백그라운드에서 깨울 때는 화면이 없어 react-query 캐시가 비어 있습니다.

**반영 시점** — 저장하면 DB는 바로 바뀌지만, 각 기기는 다음 정책 조회 때 받습니다.
실시간으로 밀어 넣지 않습니다. 급하면 푸시로 갱신을 깨우는 방법을 추가해야 합니다 (미구현).

## 4. 계정과 권한

앱 사용자(`member.users`)와 **완전히 분리**된 `config.admin_users` 를 씁니다.
관리자는 앱에 로그인할 수 없고, 앱 사용자는 관리자 화면에 들어올 수 없습니다.

| 권한 | 할 수 있는 것 |
|---|---|
| `viewer` | 보기만 |
| `editor` | 정책 수정 |
| `owner` | (앞으로) 관리자 계정 관리 |

### 계정 만들기

```
npm run admin:create
```

비밀번호는 명령 인자로 받지 않습니다. 명령 기록과 프로세스 목록에 그대로 남기 때문입니다.
같은 아이디로 다시 실행하면 비밀번호가 바뀝니다.

### 보안

| 항목 | 방식 |
|---|---|
| 비밀번호 | scrypt (Node 기본). 외부 라이브러리 없음 |
| 로그인 유지 | httpOnly 쿠키 8시간. 자바스크립트가 토큰을 읽을 수 없습니다 |
| 쿠키 범위 | `SameSite=Strict`, 경로 `/admin`, 운영에서는 `Secure` |
| 아이디 탐색 | 없는 아이디도 해시 검사를 돌려 응답 시간을 맞춥니다 |
| 값 검사 | 항목마다 최소·최대. 범위를 벗어나면 400 |

> **운영 배포 전 확인** — 이 화면은 지금 API 서버와 같은 포트에 있습니다.
> 실제 서버에 올릴 때는 `/admin` 을 사내망이나 VPN에서만 열리게 막아야 합니다.
